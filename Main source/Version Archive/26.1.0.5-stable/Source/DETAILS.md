# PulseMute Main 26.1.0.5-stable

Owner: Wrakeeb (`w-rakeeb`)

## Stable release

- Promotes the finalized `26.1.0.21-beta` feature set to the daily-use Stable channel.
- Supports two keyboard, mouse, DualSense, or DualSense Edge hotkeys.
- Includes optional Dual Hotkey mode and direct hotkey-card reassignment.
- Includes nine selectable mute/unmute feedback sounds and volume control.
- Uses the compact sidebar Settings interface by default with a legacy fallback.
- Includes General, Hotkeys, Audio, Controller, Customization, Developer, and About pages.
- Includes opt-in Developer Mode with archived-version launching and version details.
- Keeps Developer controls hidden until Developer Mode is enabled.
- Includes animated page changes and controls with an animation disable option.
- Includes selectable mute-control designs and complete interface color customization.
- Uses `#111418` for the default sidebar and `#C13545` for the default accent.
- Keeps Stable settings, startup registration, and duplicate-instance identity separate from Beta and archived releases.
- Starts this release with clean defaults; auto-start and taskbar hiding are off by default.
- Uses the full-resolution professional PulseMute logo throughout the application.
- Preserves `26.1.0.3-stable` and `26.1.0.4-stable` in the Developer version archive.

## Layout

- `PulseMute Main.exe` is the standalone Stable application.
- Editable source, dependencies, licenses, tests, and archived releases are in `Main source`.
- Release notes are stored in `Updates`.
