# PulseMute Beta 26.1.0.11-beta

## Request

- Improve the customization color picker.
- Add color-code copy and paste.

## Changes

- Preserved the complete `26.1.0.10-beta` executable, source, and update history.
- Added a PulseMute-themed color editor with live preview.
- Added editable `#RRGGBB`, `RRGGBB`, `0xRRGGBB`, and short `#RGB` color codes.
- Added direct red, green, and blue channel inputs with validation.
- Added Copy and Paste actions for color codes.
- Added eight quick-color swatches and an optional advanced system picker.
- Invalid color values are rejected without changing the saved theme.

## Validation

- Tested valid, short, prefixed, malformed, and wrong-length HEX values.
- Tested RGB boundaries and invalid channel values.
- Built and tested without opening or controlling the app UI.
