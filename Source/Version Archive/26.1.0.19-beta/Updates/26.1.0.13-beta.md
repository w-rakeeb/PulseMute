# PulseMute Beta 26.1.0.13-beta

## Request

- Move both hotkey cards below `BUILT BY WRAKEEB`.
- Add a Developer option to enable or disable the hotkey strip.
- Prevent versions from conflicting through shared settings or auto-start entries.
- Keep auto-start and hide-from-taskbar off by default for separate instances.

## Changes

- Preserved the complete `26.1.0.12-beta` executable, source, and update history.
- Reordered the standard layout to creator line, hotkey strip, and bottom controls.
- Added `Show hotkey strip` to modern and Legacy Developer Settings.
- Hiding the strip immediately returns its space to the mute control.
- Reduced the standard minimum window size from `220 x 300` to `200 x 250`.
- Added deterministic per-executable settings directories and Windows Run value names.
- Copies in different folders now start with independent settings.
- Auto-start and hide-from-taskbar remain off for an unconfigured instance.
- Removes the old shared Beta auto-start value only when it points to the current executable.

## Validation

- Tested four compact, medium, and large layouts for alignment and overlap.
- Tested hotkey-strip visibility and released mute-control space.
- Tested path-case stability and separation across Beta, Stable, and archived paths.
- Passed the full input, layout, theme, sound, archive, mouse, and controller suite.
- Did not change microphone state or Windows audio settings.
