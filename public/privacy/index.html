Privacy

Privacy Policy

Last updated September 1, 2026

No data collection

PulseMute is a local Windows utility created by Wrakeeb. It does not require an account and does not collect, sell, transmit, or share personal information.

Microphone access

PulseMute accesses Windows microphone endpoint information only to list available devices, read their mute state, and change that state when requested. It does not record, listen to, store, or transmit microphone audio.

Hotkey input

Keyboard, mouse, and supported controller input is observed locally only to detect hotkeys assigned by the user. Input data is not transmitted or used for analytics.

Local settings

Preferences such as hotkeys, appearance, selected microphone, sounds, and window placement are stored locally on the user's Windows device.

Contact

Questions or privacy requests can be submitted through PulseMute support on GitHub.
