# PulseMute PS 1.0

Owner: Wrakeeb (`w-rakeeb`)

## PlayStation edition

- Added one-button DualSense and DualSense Edge hotkeys.
- Supports all standard buttons, the dedicated Mute button, and Edge controls.
- Supports USB and Bluetooth with automatic reconnect and manual rescan.
- Keeps keyboard hotkeys available and saves the selected input.
- Uses embedded HIDSharp 2.6.4 for controller communication.

## Layout

- `PulseMute PS 1.0.exe` is the standalone main app.
- Editable and supporting files are stored in `Full source`.
- Includes repeatable controller protocol and hardware smoke tests.
