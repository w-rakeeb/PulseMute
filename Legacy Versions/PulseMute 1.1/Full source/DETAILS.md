# PulseMute 1.1

Owner: Wrakeeb (`w-rakeeb`)

## Included

- Silent microphone mute and unmute.
- One-key global shortcut with an in-app key picker.
- Compact, fully resizable interface with scaling controls.
- Stay-on-top button and system tray support.
- Automatic startup with Windows.
- Remembers window size, position, and stay-on-top state.
- Credit line: `made by Wrakeeb`.

## Version Notes

- Baseline working version for future updates.
- Controller support is not included.
- `PulseMute 1.1.exe` is the main app.
- Editable and supporting files are stored in `Full source`.
