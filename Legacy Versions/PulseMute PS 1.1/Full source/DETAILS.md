# PulseMute PS 1.1

Owner: Wrakeeb (`w-rakeeb`)

## Changes from PS 1.0

- Added Key 1 and Key 2 shortcut slots.
- Each slot accepts one keyboard or PlayStation controller button.
- Prevents repeat and duplicate-input double toggles.
- Saves both shortcut assignments independently.

## Layout

- `PulseMute PS 1.1.exe` is the standalone main app.
- Editable and supporting files are stored in `Full source`.
- Includes repeatable controller protocol and hardware smoke tests.
